# Sz3D —— 图漾风格 3D 视觉节点式编程平台

> 需求整理与技术方案（原型阶段）

## 1. 项目目标

将 3D 视觉算子封装为**节点（Node）**，节点之间通过**端口（Port）+ 连线（Connection）**相互连接，
并支持**嵌套成组（Group）**，形成完整的项目程序流程。用户可基于已有算子快速搭建项目、
验证可行性、开发原型程序供客户测试。

视觉风格参照**图漾科技 RVS（Robot Vision Suite）**：深色主题、左侧节点库、中间节点画布、
右侧属性面板、底部输出/日志面板。

## 2. 需求清单

### 2.1 节点框架（核心）
| 编号 | 需求 | 说明 |
|---|---|---|
| R-01 | 节点抽象 | 统一的 `NodeBase`：标题、分类、输入/输出端口、位置、执行逻辑 |
| R-02 | 端口 | 输入端口（可设默认值作为参数）、输出端口；端口带**数据类型** |
| R-03 | 数据类型 | 字符串 / 数值 / 布尔 / 2D 图像 / 3D 点云 / 位姿（可扩展） |
| R-04 | 连线 | 输出端口 → 输入端口，类型兼容校验，同一输入仅一路来源 |
| R-05 | 图 | `NodeGraph`：节点集合 + 连线集合，支持增删与序列化（后续） |
| R-06 | 执行器 | 拓扑排序后顺序执行；检测循环依赖；错误定位到节点 |
| R-07 | 组节点 | `GroupNode` 内嵌子图，暴露边界端口，实现嵌套成组 |
| R-08 | 节点目录 | `NodeCatalog` 注册全部可用算子，供节点库面板读取 |

### 2.2 内置算子（原型阶段）
| 类别 | 算子 | 功能 |
|---|---|---|
| 输入/输出 | 加载图像（2D） | 读取 PNG/JPG/BMP 等为 2D 图像 |
| 输入/输出 | 加载点云（3D） | 读取 PLY(ASCII)/XYZ/TXT 为点云 |
| 工具 | 生成图像 / 生成点云 | 无文件时生成演示数据 |
| 2D 处理 | 灰度化 | RGBA → 灰度 |
| 2D 处理 | 均值滤波 | 3×3 / 5×5 盒式模糊 |
| 2D 处理 | 二值化 | 阈值分割 |
| 3D 处理 | 体素降采样 | 体素网格下采样 |
| 3D 处理 | 统计离群点去除 | 基于 k 近邻距离的离群点滤波 |

### 2.3 可视化（R-09）
- 节点运算结果（字符串 / 数值 / 图像 / 点云 / 位姿）均可视化。
- 2D 图像查看器：缩放、适配、像素信息。
- 3D 点云查看器：旋转 / 平移 / 缩放、坐标轴、网格地面、按高度着色。

### 2.4 UI 框架（R-10）
- 深色主题（RVS 风格），节点按类别着色标题栏。
- 左侧：节点库（分类树，拖拽到画布）。
- 中间：节点画布（平移 / 缩放 / 拖拽节点 / 端口连线）。
- 右侧：属性面板（选中节点的参数编辑）。
- 底部：输出面板（2D 视图 / 3D 视图 / 日志 / 数据概览）。
- 顶部：工具栏（运行 / 停止 / 新建 / 示例工程 / 关于）。

## 3. 技术选型

| 项 | 选择 |
|---|---|
| 语言 / 框架 | C# / .NET 8 |
| UI | WPF（`net8.0-windows`），MVVM 轻量实现 |
| 3D 渲染 | HelixToolkit.Wpf 3.1（`HelixViewport3D`） |
| 2D 图像 | WPF `BitmapSource` / `WriteableBitmap` |
| 项目结构 | `Sz3d.Core`（纯框架 + 算子，无 UI 依赖，可复用）+ `Sz3d.App`（WPF 界面） |

## 4. 目录结构

```
src/
  Sz3d.Core/            # 节点框架与算子（无 WPF 依赖）
    Data/               # 数据类型：ImageData / PointCloudData / PoseData / Point3
    Nodes/              # NodeBase / Port / Connection / NodeGraph / NodeCatalog
      Builtin/          # 内置算子实现
    Execution/          # ExecutionContext / GraphExecutor
    Services/           # 服务抽象（IImageLoader 等）
  Sz3d.App/             # WPF 界面
    ViewModels/         # 节点/端口/连线/主界面 ViewModel
    Controls/           # 节点控件 / 端口 / 连线 / 画布
    Converters/         # 值转换器
    Themes/             # 深色主题资源
```
